# AGR Studio — Portafolio de Arath García Rubio

Portafolio web hecho desde cero con HTML, CSS y JavaScript, sin plantillas ni frameworks.
Aplica la identidad visual AGR Studio (manual v2).

- `index.html`: estructura de la página.
- `css/estilos.css`: estilos basados en la paleta y tipografía de la marca.
- `js/main.js`: lista de proyectos (arreglo `proyectos`) y lógica de la página.
- `img/marca/`: logotipos de AGR Studio.
- `img/agr/`: imágenes del proyecto de identidad AGR Studio.
- `img/`: imágenes del resto de los proyectos.
- `favicon.*`, `apple-touch-icon.png`, `icon-*.png`, `site.webmanifest`: iconos de la marca.

Sitio: https://arathgarciarubio.github.io
